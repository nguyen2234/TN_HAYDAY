# TN_HAYDAY

Nền tảng đọc truyện tranh trực tuyến hiện đại, nhanh chóng và mượt mà.

## Cấu trúc dự án

- **FE/**: Ứng dụng Frontend xây dựng bằng React 19, TypeScript, Vite, React Router 7, TanStack Query, React Bootstrap và MUI.
- **BE/**: Web API backend xây dựng bằng ASP.NET Core (.NET 8).

## Hướng dẫn khởi chạy

### Frontend (FE)
```bash
cd FE
bun install
bun run dev
```

### Backend (BE)
```bash
cd BE/WebTruyen.API
dotnet run
```
